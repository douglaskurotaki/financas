# Todo dado financeiro pertence a um Espaço, não ao Usuário

No MVP cada Usuário tem um único Espaço e não há compartilhamento, então ligar Carteiras, Cartões, Categorias e Lançamentos direto ao Usuário seria o caminho óbvio. Escolhemos o Espaço como dono desde o início porque dividir as finanças (casal, família) é uma evolução provável e é a maior lacuna do Organizze, onde compartilhar significa dividir a senha. Trocar o dono depois exigiria migrar todas as tabelas; agora custa uma tabela a mais.
